# Living Materials

Статический веб-шаблон с интерактивными вкладками для разделов о дизайне, архитектуре, путешествиях и фотографии.

## Функционал

- переключение между пятью тематическими вкладками;
- отображение активной вкладки и соответствующего контента без перезагрузки страницы;
- адаптивная верстка для разных размеров экрана;
- карточки материалов с изображениями, описанием, метаданными и ссылками.

## Стек

- HTML5;
- CSS3: Flexbox, media queries, локальные шрифты;
- JavaScript без фреймворков: обработчики кликов, `data-*` атрибуты и переключение CSS-классов;
- зависимости и база данных отсутствуют.

## Структура

```text
index.html       разметка страницы и содержимое вкладок
css/style.css    стили и адаптивная верстка
js/script.js     логика переключения вкладок
fonts/           локальные шрифты Inter и PT Serif
img/             изображения материалов
verstaem.json    описание задания
```

## Запуск

`package.json` отсутствует, поэтому установка зависимостей и npm-команды не требуются.

1. Откройте `index.html` в браузере.
2. Для локального сервера используйте расширение Live Server в VS Code или любой статический HTTP-сервер.
